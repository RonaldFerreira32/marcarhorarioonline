# Marcar Horário Online

Aplicativo de agendamento da **Barbearia Ferreira**, feito em um único arquivo `index.html` com HTML, CSS e JavaScript puros.

## Como usar

Abra o arquivo `index.html` em um navegador. Escolha um serviço, selecione um dia no calendário e depois um horário.

## Funcionalidades

- Calendário com navegação entre meses.
- Domingos e datas passadas indisponíveis.
- Horários das 9h às 18h, a cada 30 minutos, sem horários entre 12h e 13h.
- No dia atual, horários passados não são exibidos.
- Datas calculadas no horário local.

## Observações

Este é um protótipo apenas de frontend. A escolha de horário não cria nem salva uma reserva. A lista de serviços ainda contém os serviços originais do pet shop e pode ser atualizada para os serviços da barbearia.
